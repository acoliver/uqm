# The Ur-Quan Masters, Rust port

This repository runs The Ur-Quan Masters, the open-source version of Star Control II,
in Rust. SDL2 remains an external library. Game content is included in the
repository and release packages.

- [Install a release](docs/install.md)
- [Build from source](docs/building.md)
- [Play the game](docs/playing.md)
- [Development guide for contributors and agents](dev-docs/README.md)

The game derives from the Toys for Bob 3DO source release. See
[upstream attribution](sc2/README), [authors](sc2/AUTHORS) and
[license terms](sc2/COPYING). Code is GPL-2.0-or-later. Game content has separate
terms described in that license file.
