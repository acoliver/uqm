## Capture method

The OS-level captures use the native UQM title bar (`The Ur-Quan Masters v0.8.0 (Rust)`). Every capture validated that uqm was frontmost at bounds `320,30,1280,992` before the shot was taken. The presented content is 1280x960 inside that window.

Every accepted scenario run ended with `game_status: 0`, the runtime finalized and deactivated, callbacks quiescent, the trace durable, and an exact-name process check returning `NO_UQM_RUNNING`. Each teardown receipt records those fields.

The visual-pause scripts are evidence instrumentation held outside the clean source worktree, not production-source modifications.

## Contents

- `title/` main menu titled from the exact production executable.
- `luna/` the Moon/PlanetSide depart sequence: the moonbase surface before pickup, planetary orbit after automatic takeoff, and Sol navigation after leaving Luna orbit, plus its trace and teardown receipt. The driving script is `scripts/real-sol-luna-moonbase-departure.json`.
- `communication/` the comm encounter with a probe and the dispatch/dialogue assertion (`encounter=24`, `dialogue=18`), plus trace and teardown.
- `battle/` the Super Melee menu pick, battle start, and in-battle navigation with the shared battle seed recorded in the trace, plus teardown.
- `load-save/` a seeded campaign save written by the same exact executable, the populated save-slot list, the loaded game state, and a post-load movement frame. The corrected load visual script retains slot 0 selection because the populated list opens on slot 0.
- `quit/` a clean quit driven through the real UI: the in-game Quit entry selected, Really Quit on Yes selected via external real key input, a status-0 autonomous exit, a valid teardown, and `NO_UQM_RUNNING`.
- `manifest/` the machine-readable production build manifest for the exact executable.

None of this should be taken as a claim that quit is proven by the title screenshot. Quit is independently evidenced by the quit scenario's trace, teardown, and process check.

## Quit script validation note

The retained quit automation script ends with steps that run after the process has exited. Those steps are unreachable by construction; script validation requires one final `finish` action, so the script lists post-exit captures purely to satisfy that constraint. The quit itself was proven by the real-UI interaction and the status-0 autonomous exit, not by any later capture. The window log shows those post-exit captures failing with `no_window` and `no_uqm_process`, which is the expected shape after a clean quit.
