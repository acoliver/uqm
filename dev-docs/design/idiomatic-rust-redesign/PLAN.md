# Replace internal C conventions along production paths

**First delivery: a content owner that resolves shipped assets and settings without process registries, with a tested path from mount to navigation art.** Establish the successful lookup, missing-asset, retry and release checks on the old path before editing it. A plan that ends at this delivery leaves gameplay, media and proof state split between competing owners. Completion requires U01 through U18 and the finish checks below.

Baseline: [`678f8c11defe28a85cfccac29899410209e9963c`](https://github.com/acoliver/uqm/tree/678f8c11defe28a85cfccac29899410209e9963c). The [audit index and topic matrix](README.md) specifies scope and path abbreviations. [Media](media.md), [world](world.md), [battle](battle.md), [interaction](interaction.md) and [verification](verification.md) supply the call sites, existing tests and additional negative cases for each unit. All checks and benchmarks below are future work. No tests ran in preparing this plan.

## Working contract

1. **Establish the baseline.** Record the pin, toolchain/features, target, binary and content hashes, addon order, settings, seeds, scripts, fixture use and the actual gate results. Keep failures visible. For each change capture expected success, ordering, exit and failure behavior on the production entry before replacing anything. Inject a failure at each fallible acquisition, publication or commit in scope. Verify the check detects a wrong outcome, such as advancing RNG during a read or reporting success after a failed write. Mock only external capabilities. Preserve independent reference implementations as test oracles when they discriminate wrong answers.
2. **Separate corrections.** A structural unit expects identical observables. A correction gets its own change, reproducer, expected difference, evidence of the old behavior, and regression on the same live entry. Land each reproducer and fix together after seeing it fail on the parent. Correct a demonstrated hazard first if otherwise the ownership change would hide it. If the reproducer disproves the finding, record the invariant and keep the behavior. No golden refresh accompanying a rename, new owner or faster implementation.
3. **Replace a working path in one change.** Introduce the owner, migrate all writers, readers, feature variants, reexports, observers and fixture callers of the superseded path and delete it in the same PR. Units with many authored behaviors can repeat this rule by complete family. No dual engines, permanent forwarding facade, generic `Services` locator or later caller-cleanup PR. Search definitions, imports, `#[path]`, cfg builds, scripts and public crate APIs before claiming deletion. Identify any actual downstream public contract and handle it at the external boundary.
4. **Respect authority.** Ordinary Rust values, exclusive borrows and iterators are the default. `Application` owns host lifetimes; `Game` owns campaign and gameplay RNG; a mode borrows the needed owners for its duration. Types distinguish ready assets, running phases and terminal outcomes. Use cheap generational IDs for objects that outlive a borrow and retained leases for queued media. Cross a thread with owned work, bounded buffers or immutable observations. Do not put `World` behind a shared mutex. Scope a trait to a real variation such as a device, a transport or an authored behavior. `Result` preserves an external error and its source; `Option` expresses allowed absence or bounded allocation failure; cancellation, retreat and normal EOF have domain meanings. Invalid internal construction fails at its owner.

## Permanent regression and compatibility policy

**Per change.** Start with changed-crate tests and focused production traces. On the candidate keep fmt, quality/layers/unsafe and dependency checks, clippy, workspace tests, coverage and release builds; retain the complete exact headless check, failure scenarios and selected platform/jitter repetitions. Use the commands/feature sets from `.github/workflows/ci.yaml` (including `cargo xtask quality`, `cargo xtask clippy`, coverage and `parity check --base`), not the root package's default test subset. Check receipts for actual execution; skipped jobs do not qualify.
